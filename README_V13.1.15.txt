OYONID MAP V13.1.15 — REALIZATION MINIMAL UI

Perubahan:
1. Mode Realisasi disederhanakan: panel tanggal/statistik di atas, kontrol playback minimal di bawah.
2. Kontrol playback memakai satu tombol Putar/Jeda, Ulang, kecepatan, dan Buat Ulang Video.
3. Kotak foto di kiri bawah selalu muncul selama Mode Realisasi; foto pelanggan/lokasi tampil saat cocok dengan titik playback, selain itu muncul placeholder.
4. Video dibangun ulang dari data GPS pada tanggal realisasi terpilih, termasuk titik GPS pelanggan yang sudah selesai.
5. Ekspor video mengizinkan satu titik GPS (bukan mensyaratkan minimal dua titik).
6. Titik pelanggan selesai yang memiliki koordinat tetapi data jam lama kosong tetap dapat masuk ke animasi berdasarkan urutan data.

Catatan:
- Gunakan Chrome terbaru untuk pembuatan video.
- Foto hanya muncul bila foto sudah tersimpan dan dapat dipasangkan ke pelanggan/titik.
- Uji lokal sebelum mengganti deployment produksi.
